Directives let you give an element a behaviour you write once and reuse anywhere, like keeping the focus inside a dialog, closing a menu on a click outside it, or focusing a field once it shows. In Unframework you declare one with `defineDirective`, and an element applies it as `v-focus-trap={open.value}`. Think of the same `onMounted` and `onUnmounted` pair copied into every dialog, a listener left on `document` after the menu is gone, or a focus trap that forgets where the focus came from.

This page walks you through writing a directive and applying it. We'll look at:

- **A directive of your own:** `defineDirective`, its hooks, and what each framework receives.
- **A function as the value:** a click outside that calls the component back.
- **When the hooks run:** the browser only, in Vue's order.
- **What the compiler checks:** names, values and what isn't supported yet.

## A directive of your own

Let's start with a focus trap. A directive lives in a `.uf.ts` module, beside your composables or in a module of its own, and is a named export whose name is `v` and an upper-case letter. `defineDirective<T>` takes the value's type, and an object of hooks: `mounted(el, value)`, `updated(el, value, oldValue)` and `unmounted(el)`. This one keeps each element's state in a `WeakMap` the hooks share:

<!-- prettier-ignore -->
```ts [focusTrap.uf.ts]
// A focus trap (ADR-0099): once its element is in the document, the focus moves to its first
// control, and Tab and Shift+Tab stay among its controls. When it leaves, the focus returns to
// what had it before. Each element's state lives in a table the hooks share.
import { defineDirective } from "@uxfront/unframework";

interface Trap {
  previous: HTMLElement | null;
  onKeydown: (event: KeyboardEvent) => void;
}

const FOCUSABLE =
  "button:not([disabled]), [href], input:not([disabled]), [tabindex]:not([tabindex='-1'])";
const traps = new WeakMap<HTMLElement, Trap>();

export const vFocusTrap = defineDirective<boolean>({
  mounted(el, active) {
    const onKeydown = (event: KeyboardEvent) => {
      if (event.key !== "Tab") return;
      const controls = [...el.querySelectorAll<HTMLElement>(FOCUSABLE)];
      const first = controls[0];
      const last = controls.at(-1);
      if (!first || !last) return;
      if (event.shiftKey && document.activeElement === first) {
        event.preventDefault();
        last.focus();
      } else if (!event.shiftKey && document.activeElement === last) {
        event.preventDefault();
        first.focus();
      }
    };
    const previous = document.activeElement instanceof HTMLElement ? document.activeElement : null;
    traps.set(el, { previous, onKeydown });
    el.addEventListener("keydown", onKeydown);
    if (active) el.querySelector<HTMLElement>(FOCUSABLE)?.focus();
  },
  unmounted(el) {
    const trap = traps.get(el);
    if (!trap) return;
    el.removeEventListener("keydown", trap.onKeydown);
    traps.delete(el);
    trap.previous?.focus();
  },
});
```

A component imports it by name and applies it in kebab case, `vFocusTrap` as `v-focus-trap`. The dialog renders behind a condition, so its `mounted` runs once the dialog is in the document, and its `unmounted` once the condition removes it:

<!-- prettier-ignore -->
```tsx [Settings.uf.tsx]
import { ref } from "@uxfront/unframework";

import { vFocusTrap } from "./focusTrap.uf.ts";

export default function Settings() {
  const open = ref(false);

  function close() {
    open.value = false;
  }

  function onKeydown(event: KeyboardEvent) {
    if (event.key === "Escape") close();
  }

  return (
    <section class="settings" aria-label="Settings">
      <button type="button" onClick={() => (open.value = true)}>
        Open
      </button>
      {open.value ? (
        <div
          role="dialog"
          aria-label="Preferences"
          tabindex="-1"
          class="dialog"
          v-focus-trap={open.value}
          onKeydown={onKeydown}
        >
          <button type="button">Theme</button>
          <button type="button">Language</button>
          <button type="button" onClick={close}>
            Close
          </button>
        </div>
      ) : null}
    </section>
  );
}
```

Each framework receives the directive in its own idiom. Vue gets its own custom directive, Svelte an attachment, Solid a ref factory and Angular an attribute directive. React and Qwik have no directive, so they get the plain hooks, which a small helper in each component runs. Astro runs nothing in the page, so it writes no file for a directive, and its component renders the dialog without it:

```ts [v-focus-trap.ts]
import { queueHook } from "./_unframework/queueHook";
import { DestroyRef, Directive, ElementRef, afterRenderEffect, inject, input } from "@angular/core";

interface Trap {
  previous: HTMLElement | null;
  onKeydown: (event: KeyboardEvent) => void;
}

const FOCUSABLE =
  "button:not([disabled]), [href], input:not([disabled]), [tabindex]:not([tabindex='-1'])";
const traps = new WeakMap<HTMLElement, Trap>();

/** The hooks of a directive, which `runDirective` runs on its element. */
interface DirectiveHooks<E extends Element, T> {
  mounted?(el: E, value: T): unknown;
  updated?(el: E, value: T, oldValue: T): unknown;
  unmounted?(el: E): unknown;
}

/** The checks `watchDocument` calls, and its observer while it has any. */
const documentWatches: { checks: Set<() => void>; observer?: MutationObserver } = {
  checks: new Set(),
};

/**
 * Calls `check` after each change to the document's tree, through one `MutationObserver` for
 * every watch, and returns the end of the watch.
 */
function watchDocument(check: () => void): () => void {
  const { checks } = documentWatches;
  if (!documentWatches.observer) {
    documentWatches.observer = new MutationObserver(() => {
      for (const each of [...checks]) each();
    });
    documentWatches.observer.observe(document, { childList: true, subtree: true });
  }
  checks.add(check);
  return () => {
    checks.delete(check);
    if (!checks.size) {
      documentWatches.observer?.disconnect();
      documentWatches.observer = undefined;
    }
  };
}

/**
 * Each directive's elements: the value each last received, whether `mounted` ran, whether it
 * left its caller's list, how many runs took it up, and the end of its watch on the document.
 */
const directiveStates = new WeakMap<
  object,
  WeakMap<
    Element,
    { value: unknown; mounted: boolean; left: boolean; runs: number; unwatch: () => void }
  >
>();

/**
 * The check of a directive's elements: `mounted` once an element is in the document, and
 * `unmounted` once it leaves. A caller that lists its elements passes `follow`, which takes an
 * element out of the list as it leaves and back in if it returns, for the caller's next run to
 * mount it with the value of then; meanwhile the element belongs to a weak watch alone
 * (`watchLeft`). Declared apart from `runDirective`, whose scope holds
 * the element, so nothing it makes keeps a left element alive.
 */
function directiveCheck<E extends Element, T>(
  directive: DirectiveHooks<E, T>,
  elements: WeakMap<
    Element,
    { value: unknown; mounted: boolean; left: boolean; runs: number; unwatch: () => void }
  >,
  follow: { leave(element: E): void; back(element: E): void } | undefined,
): (target: E) => void {
  const check = (target: E): void => {
    const current = elements.get(target);
    if (!current || current.mounted === target.isConnected) return;
    if (current.left) {
      // Back in the document, it rejoins the list, and the caller's next run mounts it with the
      // value of then.
      if (target.isConnected) follow?.back(target);
      return;
    }
    current.mounted = target.isConnected;
    if (current.mounted) {
      const mounted = current.value as T;
      queueHook(target, () => directive.mounted?.(target, mounted), "mounted");
      return;
    }
    queueHook(target, () => directive.unmounted?.(target), "unmounted");
    if (!follow) return;
    current.left = true;
    current.unwatch();
    current.unwatch = watchLeft(target, check);
    follow.leave(target);
  };
  return check;
}

/**
 * Watches an element that left its caller's list through a `WeakRef`: `check` runs on it
 * after each change of the document while it lives, and the watch ends once it is collected.
 */
function watchLeft<E extends Element>(element: E, check: (target: E) => void): () => void {
  const left = new WeakRef(element);
  const unwatch = watchDocument(() => {
    const kept = left.deref();
    if (kept) check(kept);
    else unwatch();
  });
  return unwatch;
}

/**
 * Runs a directive's hooks on its element: `mounted` once the element is in the document,
 * `updated` for a value that changed while it is, and `unmounted` once it leaves, which
 * projected content may do and come back. A caller that lists its elements passes `follow`
 * (`directiveCheck`): an element that left the list stays with its weak watch, and one that is gone
 * for good is collected, which ends its watch at the next change of the document. The stop it
 * returns, called when the element's owner goes, unmounts the element a microtask later, unless a
 * later run took it up or it left a list.
 */
function runDirective<E extends Element, T>(
  directive: DirectiveHooks<E, T>,
  element: E,
  value: T,
  follow?: { leave(element: E): void; back(element: E): void },
): () => void {
  let own = directiveStates.get(directive);
  if (!own) {
    own = new WeakMap();
    directiveStates.set(directive, own);
  }
  const elements = own;
  const check = directiveCheck(directive, elements, follow);
  let state = elements.get(element);
  if (state?.left) {
    // A left element its caller lists again: it is followed as any other.
    state.left = false;
    state.unwatch();
    state.unwatch = watchDocument(() => check(element));
  }
  if (state) {
    state.runs += 1;
    if (!Object.is(value, state.value)) {
      const previous = state.value as T;
      state.value = value;
      if (state.mounted) {
        queueHook(element, () => directive.updated?.(element, value, previous), "updated");
      }
    }
  } else {
    state = {
      value,
      mounted: false,
      left: false,
      runs: 0,
      unwatch: watchDocument(() => check(element)),
    };
    elements.set(element, state);
  }
  check(element);
  const taken = state;
  const runs = taken.runs;
  return () => {
    queueMicrotask(() => {
      if (elements.get(element) !== taken || taken.runs !== runs || taken.left) return;
      taken.unwatch();
      elements.delete(element);
      if (taken.mounted) queueHook(element, () => directive.unmounted?.(element), "unmounted");
    });
  };
}

@Directive({ selector: "[vFocusTrap]" })
export class VFocusTrap {
  readonly vFocusTrap = input.required<boolean>();

      mounted(el: HTMLElement, active: boolean) {
        const onKeydown = (event: KeyboardEvent) => {
          if (event.key !== "Tab") return;
          const controls = [...el.querySelectorAll<HTMLElement>(FOCUSABLE)];

          const last = controls.at(-1);
          if (!first || !last) return;
          if (event.shiftKey && document.activeElement === first) {
            event.preventDefault();
            last.focus();
          } else if (!event.shiftKey && document.activeElement === last) {
            event.preventDefault();
            first.focus();
          }
        };
        const previous =
          document.activeElement instanceof HTMLElement ? document.activeElement : null;
        traps.set(el, { previous, onKeydown });
        el.addEventListener("keydown", onKeydown);
        if (active) el.querySelector<HTMLElement>(FOCUSABLE)?.focus();
      },
      unmounted(el: HTMLElement) {
        const trap = traps.get(el);
        if (!trap) return;
        el.removeEventListener("keydown", trap.onKeydown);
        traps.delete(el);
        trap.previous?.focus();
      },
    };
    const element = this.element.nativeElement;
    let stop: (() => void) | undefined;
    afterRenderEffect(() => {
      stop = runDirective(hooks, element, this.vFocusTrap());
    });
    inject(DestroyRef).onDestroy(() => stop?.());
  }
}
```

## A function as the value

Now let's look at a click outside. Its value is a function the directive calls when a click lands outside its element, so the menu decides what closing means. Pass a setup function by its name, as you'd pass a listener: a function written in place would be a new value at every render on some frameworks.

<!-- prettier-ignore -->
```ts [clickOutside.uf.ts]
// Click outside (ADR-0099): the value is a function the directive calls when a click lands
// outside its element. The listener is the document's, added once the element is mounted and
// removed once it leaves; `updated` keeps the function the last render gave.
import { defineDirective } from "@uxfront/unframework";

interface Outside {
  callback: () => void;
  onClick: (event: MouseEvent) => void;
}

const outsides = new WeakMap<HTMLElement, Outside>();

export const vClickOutside = defineDirective<() => void>({
  mounted(el, callback) {
    const outside: Outside = {
      callback,
      onClick: (event) => {
        if (!el.contains(event.target as Node)) outside.callback();
      },
    };
    outsides.set(el, outside);
    document.addEventListener("click", outside.onClick);
  },
  updated(el, callback) {
    const outside = outsides.get(el);
    if (outside) outside.callback = callback;
  },
  unmounted(el) {
    const outside = outsides.get(el);
    if (outside) document.removeEventListener("click", outside.onClick);
    outsides.delete(el);
  },
});
```

React keeps `close` one stable function, Angular makes it an arrow member and Qwik a QRL, so `updated` runs on no framework just because the component rendered again.

## A directive on each row

A directive works on each row a list renders, and on each element a scoped slot's fill renders, and its value may read the row's item or the fill's props. Each element gets its own hooks, with its own value: renaming one row runs `updated` on that row alone, and removing a row runs `unmounted` on it alone. On Solid, a scoped fill whose child passes it new props renders a new element, so its directive runs `unmounted` and `mounted` there instead ([semantics](/docs/reference/semantics#outside-the-contract)). Here each row traces its label, one row applies two directives, one listens beside its directive, and one's value reads the component's state too:

<!-- prettier-ignore -->
```tsx [Menu.uf.tsx]
import { ref } from "@uxfront/unframework";

import { vMark } from "./mark.uf.ts";
import Picker from "./Picker.uf.tsx";
import { vTrace } from "./trace.uf.ts";

// A directive on each row a list renders, and on each element a scoped fill renders, whose value
// reads the row's item or the fill's props (ADR-0108): each element gets its own hooks with its
// own value. A row applies two such directives, another listens beside one, another's value
// reads the component's state too, and one in a branch of a row reads what the branch narrows.
export default function Menu() {
  const items = ref<{ id: string; label: string; note?: string }[]>([
    { id: "a", label: "Alpha", note: "First" },
    { id: "b", label: "Beta" },
    { id: "c", label: "Gamma" },
  ]);
  const prefix = ref("Open");
  const focused = ref(0);

  return (
    <section class="menu" aria-label="Menu">
      <ul aria-label="Items">
        {items.value.map((item) => (
          <li key={item.id} data-name={item.id} v-trace={item.label}>
            {item.label}
            {item.note ? (
              <b data-name={`note-${item.id}`} v-trace={item.note}>
                {item.note}
              </b>
            ) : null}
          </li>
        ))}
      </ul>
      <ul aria-label="Marked">
        {items.value.map((item) => (
          <li key={item.id} data-name={`both-${item.id}`} v-trace={item.label} v-mark={item.id}>
            {item.label}
          </li>
        ))}
      </ul>
      <div class="focus">
        {items.value.map((item) => (
          <button
            key={item.id}
            type="button"
            data-name={`focus-${item.id}`}
            onFocusin={() => focused.value++}
            v-trace={item.label}
          >
            Focus {item.label}
          </button>
        ))}
      </div>
      <output>{focused.value}</output>
      <ul aria-label="Prefixed">
        {items.value.map((item) => (
          <li
            key={item.id}
            data-name={`prefixed-${item.id}`}
            v-trace={`${prefix.value} ${item.label}`}
          >
            {item.label}
          </li>
        ))}
      </ul>
      <Picker>
        {{
          option: ({ option }) => (
            <span data-name={`option-${option.id}`} v-trace={`${prefix.value} ${option.label}`}>
              {option.label}
            </span>
          ),
        }}
      </Picker>
      <button
        type="button"
        onClick={() =>
          (items.value = items.value.map((item) =>
            item.id === "a" ? { id: "a", label: "Alpha 2", note: "First" } : item,
          ))
        }
      >
        Rename first
      </button>
      <button type="button" onClick={() => (items.value = [...items.value].reverse())}>
        Reverse
      </button>
      <button
        type="button"
        onClick={() => (items.value = items.value.filter((item) => item.id !== "b"))}
      >
        Remove second
      </button>
      <button
        type="button"
        onClick={() => (items.value = [...items.value, { id: "d", label: "Delta" }])}
      >
        Add item
      </button>
      <button type="button" onClick={() => (prefix.value = "Close")}>
        Change prefix
      </button>
    </section>
  );
}
```

React has no directive, so each row makes its ref callback from its value as it renders, through the function a `useElementDirective(vTrace)` call at the component's top level returns. Qwik's row passes it as it renders too, `ref={collectValues(traceElements, [item.label])}`, so a value that also reads the component's state renders the row again when that state changes. Vue, Svelte, Solid and Angular apply a directive to each row already.

## When the hooks run

The hooks run in the browser only. The server never runs one, so the server's HTML holds nothing a hook writes, and hydration has nothing of it to compare:

- `mounted` runs once per element, once the element is in the DOM, with that render's value.
- `updated` runs after a render in which the value changed, as `Object.is` compares it, with the new value and the previous one. A render that leaves the value the same doesn't run it, though Vue calls a directive after every update of its component.
- `unmounted` runs once, when the element leaves the DOM or its component unmounts. The element may already be detached, as it is on Vue.

Within one render, every `unmounted` runs before any `mounted`, a descendant's hook runs before its ancestor's, and siblings' in document order, which is Vue's own order. React, Solid, Angular and Qwik keep it through a small queue, one for the whole page, so a hook may run in a microtask after the framework's own, and a directive from a `.uf.ts` module sorts with a component's own. The [semantics contract](/docs/reference/semantics#directives) has the rule, and the few cases outside it.

## What the compiler checks

A directive is declared once, as a top-level `const` that `defineDirective<T>` initialises, with method hooks that read their parameters, the browser's globals, and the module's constants and imports. Anything else is [UF2037](/docs/reference/diagnostics#UF2037): a call in a setup, no type argument, an unknown hook, or a hook that calls the authoring API. The names of Vue's own directives, like `v-if` and `v-show`, stay Vue's.

An element applies a directive the module declares or imports, or it's [UF3055](/docs/reference/diagnostics#UF3055). A directive goes on an element, with a value, which isn't an object or array literal or a function written in place, or it's [UF3056](/docs/reference/diagnostics#UF3056). Pass a state, a derived value, a prop, a setup function or a primitive instead.

The value's type is the `T` of the directive's `defineDirective<T>`. TypeScript doesn't type a dashed JSX attribute, so your editor accepts `v-focus-trap={1}`. With the tsgo type oracle, `typeOracle: "tsgo"` in your [configuration](/docs/tooling/configuration#fields), the compiler checks each value where it's written, narrowed by its branch, and reports one of another type as [UF6007](/docs/reference/diagnostics#UF6007). The default oracle doesn't check it.

These aren't supported yet:

- Arguments and modifiers, like `v-focus-trap:outer` and `v-focus-trap_once`. Pass what the directive needs as its value.
- A directive among a spread's keys.

Keep in mind that TypeScript doesn't read `v-focus-trap` as a use of `vFocusTrap`, so a lint rule like `no-unused-vars` flags the import. We recommend ignoring names that start with `v` and an upper-case letter in your `.uf.tsx` files, as this repository's own lint config does: `varsIgnorePattern: "^(?:_|v[A-Z][A-Za-z0-9]*$)"`.
