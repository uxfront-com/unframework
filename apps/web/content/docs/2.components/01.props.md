A component takes its props as its only parameter, typed by an object type. You destructure them, with a static default for any optional prop, or read them from one object as `props.name`. The compiler copies the type into every output and declares the props the way each framework does.

## Destructured props

The canonical form destructures each prop by its own name:

<!-- prettier-ignore -->
```tsx [ProductTile.uf.tsx]
export interface ProductTileProps {
  name: string;
  price: number;
  stock: number;
  available?: boolean;
}

export default function ProductTile({ name, price, stock, available = true }: ProductTileProps) {
  return (
    <article class="product-tile" aria-label={name}>
      <h2>{name}</h2>
      <p>Price: {price} EUR</p>
      <p data-stock={stock}>{stock} in stock</p>
      <p>{available ? "Available to order" : "Currently unavailable"}</p>
      <button type="button" disabled={!available}>
        Add {name} to basket
      </button>
    </article>
  );
}
```

Each framework gets the same props, declared its own way:

```tsx [ProductTile.tsx]
import type { ComponentPropsWithRef } from "react";

export interface ProductTileProps {
  name: string;
  price: number;
  stock: number;
  available?: boolean;
}

export type ProductTileAttributes = Omit<
  ComponentPropsWithRef<"article">,
  "name" | "price" | "stock" | "available" | "children"
>;

export default function ProductTile({
  name,
  price,
  stock,
  available = true,
  className,
  style,
  ...attributes
}: ProductTileProps & ProductTileAttributes) {
  return (
    <article
      className={cx("product-tile", className)}
      aria-label={name}
      style={style}
      {...attributes}
    >
      <h2>{name}</h2>
      <p>Price: {price} EUR</p>
      <p data-stock={stock}>{stock} in stock</p>
      <p>{available ? "Available to order" : "Currently unavailable"}</p>
      <button type="button" disabled={!available}>
        Add {name} to basket
      </button>
    </article>
  );
}

/** Joins class names, and the keys of an object's truthy entries, into one `className`. */
function cx(...parts: unknown[]): string {
  const names: string[] = [];
  for (const part of parts) {
    if (typeof part === "string") {
      if (part) names.push(part);
    } else if (part && typeof part === "object") {
      for (const [key, on] of Object.entries(part)) {
        if (on) names.push(key);
      }
    }
  }
  return names.join(" ");
}
```

#angular

```ts [product-tile.ts]
import { isPlatformBrowser } from "@angular/common";
import {
  Component,
  Directive,
  ElementRef,
  type OnChanges,
  type OnDestroy,
  type OnInit,
  PLATFORM_ID,
  Renderer2,
  inject,
  input,
  viewChild,
} from "@angular/core";

export interface ProductTileProps {
  name: string;
  price: number;
  stock: number;
  available?: boolean;
}

/** The scope attributes taken off each host, for the roots its component renders later. */
const scopes = new WeakMap<Element, string[]>();

/**
 * Gives a root node of its component the scope attributes the component's styled parents put on
 * its host (ADR-0063), and takes them off the host, which keeps only `display: contents`.
 */
@Directive({ selector: "[ufScope]" })
export class ScopeAttributes implements OnInit {
  readonly ufScope = input.required<HTMLElement>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);

  ngOnInit(): void {
    const host = this.ufScope();
    let names = scopes.get(host);
    if (!names) {
      names = host.getAttributeNames().filter((name) => name.startsWith("data-uf-"));
      for (const name of names) this.renderer.removeAttribute(host, name);
      scopes.set(host, names);
    }
    for (const name of names) this.renderer.setAttribute(this.element.nativeElement, name, "");
  }
}

/** A native listener of each event a consumer passes, by the event's name (ADR-0118). */
type Listeners = { [K in keyof HTMLElementEventMap]?: (event: HTMLElementEventMap[K]) => void };

/**
 * Puts what a consumer passes the component, and the component does not declare, on the element
 * that takes it (ADR-0118): the attributes, the consumer's winning over the element's own, and
 * the native listeners, which run after the element's own.
 */
@Directive({ selector: "[ufFallthrough]" })
export class Fallthrough implements OnChanges, OnDestroy {
  readonly ufFallthrough = input.required<{
    attributes: Record<string, unknown> | undefined;
    listeners: Listeners | undefined;
  }>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);
  private readonly browser = isPlatformBrowser(inject(PLATFORM_ID));
  private readonly listening = new Map<string, { handler: unknown; stop: () => void }>();
  private written: Record<string, unknown> = {};

  ngOnChanges(): void {
    const element = this.element.nativeElement;
    const { attributes = {}, listeners = {} } = this.ufFallthrough();
    for (const name of Object.keys(this.written)) {
      if (!(name in attributes)) this.renderer.removeAttribute(element, name);
    }
    for (const [name, value] of Object.entries(attributes)) {
      if (value === null || value === undefined) this.renderer.removeAttribute(element, name);
      else this.renderer.setAttribute(element, name, String(value));
    }
    this.written = attributes;
    if (!this.browser) return;
    const handlers = new Map(Object.entries(listeners));
    for (const [event, { handler, stop }] of this.listening) {
      if (handlers.get(event) === handler) continue;
      stop();
      this.listening.delete(event);
    }
    for (const [event, handler] of handlers) {
      if (handler === undefined || this.listening.has(event)) continue;
      this.listening.set(event, { handler, stop: this.renderer.listen(element, event, handler) });
    }
  }

  ngOnDestroy(): void {
    for (const { stop } of this.listening.values()) stop();
  }
}

@Component({
  selector: "uf-product-tile",
  imports: [ScopeAttributes, Fallthrough],
  host: { "[attr.class]": "null", "[attr.style]": "'display: contents;'" },
  preserveWhitespaces: false,
  template: `
    @let name = this.name();
    @let price = this.price();
    @let stock = this.stock();
    @let available = this.available();
    <article
      class="product-tile"
      [attr.aria-label]="'aria-label' in (this.ufAttributes() ?? {}) ? this.ufAttributes()?.['aria-label'] : name"
      [class]="this.class()"
      [style]="this.style()"
      [ufFallthrough]="{ attributes: this.ufAttributes(), listeners: this.ufListeners() }"
      [ufScope]="this.host"
      #ufElement
    >
      <h2>{{ name }}</h2>
      <p>Price: {{ price }} EUR</p>
      <p [attr.data-stock]="stock">{{ stock }} in stock</p>
      <p>{{ available ? "Available to order" : "Currently unavailable" }}</p>
      <button
        type="button"
        [attr.disabled]="!available ? '' : null"
      >Add {{ name }} to basket</button>
    </article>
  `,
})
export default class ProductTile {
  readonly name = input.required<string>();
  readonly price = input.required<number>();
  readonly stock = input.required<number>();
  readonly available = input<boolean, boolean | undefined>(true, {
    transform: (value) => (value === undefined ? true : value),
  });
  readonly class = input<string>();
  readonly style = input<Record<string, string | null | undefined>>();
  readonly ufAttributes = input<Record<string, unknown>>();
  readonly ufListeners = input<Listeners>();
  readonly ufElement = viewChild<ElementRef<HTMLElement>>("ufElement");
  protected readonly host = inject<ElementRef<HTMLElement>>(ElementRef).nativeElement;
}
```

::

- React and Qwik keep the pattern and its defaults in the component's parameter.
- Vue destructures `defineProps<P>()`. An optional prop without a default gets `= undefined`, so Vue does not turn an absent boolean prop into `false`.
- Svelte destructures `$props()`.
- Angular declares one signal input per prop: `input.required<T>()` for a required prop, `input<T>()` for an optional one, and `input<T, T | undefined>(default, { transform })` for one with a default. The transform applies the default to an explicit `undefined` too. The template reads each input once, with `@let`.
- Solid never destructures its props, because they are reactive getters. It merges the defaults in with `mergeProps`, typed `satisfies Partial<P>`, and reads every prop as `props.name`. A default that holds an object or an array literal makes the defaults a `const defaults: Required<Pick<P, …>>` of their own, as in `Notice` below: `satisfies` would type the prop by the literal, without the optional members an object leaves out, and an array of `"info"` as `"info"[]` rather than `Tone[]`.
- Astro names the type `Props` and destructures `Astro.props`.

A destructured prop that the template never reads is left out of the pattern, so the outputs pass their frameworks' unused-variable rules. The type still declares it, and Angular still declares its input. Vue keeps an optional one, because `vue/require-default-prop` asks for its default, under a local whose `_` tells the lint it is unread:

## The props object

When no prop has a default, a component can take its props as one object:


## Types

The props type is an inline object type, or a local `interface` or `type` alias:

<!-- prettier-ignore -->
```tsx [ProductSpec.uf.tsx]
type Availability = "in-stock" | "backorder" | "discontinued";

interface Finish {
  sku: string;
  label: string;
}

export interface ProductSpecProps {
  name: string;
  availability: Availability;
  size: { width: number; depth: number; unit: "cm" | "in" };
  finishes: Finish[];
```

Every output copies the declarations the props reach, exactly as written, and exports them as the source does. Angular, for example, types its inputs with them:

<!-- prettier-ignore -->
```ts [product-spec.ts]
readonly finishes = input.required<Finish[]>();
```

A member is a property with a plain name, declared once ([UF2001](/docs/reference/diagnostics#UF2001)). Its type can be built from:

- `string`, `number`, `boolean`, `null` and `undefined`;
- string, number and boolean literal types;
- unions of these;
- arrays: `T[]`, `readonly T[]`, `Array<T>` and `ReadonlyArray<T>`;
- object type literals, and local interfaces and aliases, nested to any depth;
- interfaces and aliases imported from a `.ts` module, a child's module or a package, `extends` chains, intersections, generic declarations and the five utility types ([Types and generics](/docs/components/types-and-generics)).

Anything else is a diagnostic at the type:

| Type                                                                                                 | Why                                                                                                                                                         | Code                                                                                                                                                             |
| ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A function type or a method                                                                          | A callback is an [event](/docs/components/events#component-events), which `defineEmits` declares, and a render function is a [slot](/docs/components/slots) | [UF1002](/docs/reference/diagnostics#UF1002): use an event or a slot                                                                                             |
| A global type, such as `Date`                                                                        | The compiler reads only the types the module declares or imports                                                                                            | [UF6001](/docs/reference/diagnostics#UF6001)                                                                                                                     |
| `any`, `unknown`, `object`, `{}`, `symbol`, `bigint` or a tuple                                      | The targets' props can't declare it (ADR-0034)                                                                                                              | [UF6002](/docs/reference/diagnostics#UF6002)                                                                                                                     |
| A template literal type, an index signature, a computed key, `keyof`, a conditional or a mapped type | The default type oracle reads types as written, and these need a type checker                                                                               | [UF6002](/docs/reference/diagnostics#UF6002): the tsgo type oracle evaluates some of them ([What stays out](/docs/components/types-and-generics#what-stays-out)) |
| An enum                                                                                              | An enum declaration is itself UF1002, and the default type oracle doesn't evaluate one                                                                      | [UF1002](/docs/reference/diagnostics#UF1002) and [UF6002](/docs/reference/diagnostics#UF6002)                                                                    |
| A props type that isn't an object type, such as a union of two object types                          | The targets declare props as the members of one object type                                                                                                 | [UF6004](/docs/reference/diagnostics#UF6004)                                                                                                                     |
| A union of a boolean with `string`, `""` or the prop's own kebab-case name                           | Vue reads `""` and the prop's own name as `true` for such a prop, and its casting rule stays (ADR-0034)                                                     | [UF1002](/docs/reference/diagnostics#UF1002): give the prop one kind                                                                                             |

A type declaration that no component's props reach is UF1002 unless the module exports it, since no output would declare it. Every output exports one the module exports ([Exported types](/docs/components/types-and-generics#exported-types)). `import type` reads from a `.ts` module, a child's module or a package. Keep a type that several components share in a `.ts` module: the Vite plugin joins the components of one file into one module on React, Solid, Qwik and Angular, where two outputs that both declare a type clash. (Vue, Svelte and Astro files hold one component each.)

A default goes on an optional prop, in the pattern:

<!-- prettier-ignore -->
```tsx [Notice.uf.tsx]

  message,
  title = "Notice",
  tone = "info",

```

A default is a static value: a string, number, boolean or `null` literal, a negated number, a template literal without expressions, or an array or object literal of those. It cannot read anything, not a prop, a global or a function's result ([UF2002](/docs/reference/diagnostics#UF2002)): Vue hoists defaults out of the component, and Angular reads them before any input is set. Write the value itself, or compute it in the template (`pageCount ?? 10`).

```tsx [Notice.tsx]
    if (typeof part === "string") {
      if (part) names.push(part);
    } else if (part && typeof part === "object") {
```

```ts [notice.ts]
const scopes = new WeakMap<Element, string[]>();

/**
 * Gives a root node of its component the scope attributes the component's styled parents put on
 * its host (ADR-0063), and takes them off the host, which keeps only `display: contents`.
 */
@Directive({ selector: "[ufScope]" })
export class ScopeAttributes implements OnInit {
  readonly ufScope = input.required<HTMLElement>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);

  ngOnInit(): void {
    const host = this.ufScope();
    let names = scopes.get(host);
    if (!names) {
      names = host.getAttributeNames().filter((name) => name.startsWith("data-uf-"));
      for (const name of names) this.renderer.removeAttribute(host, name);
      scopes.set(host, names);
    }
    for (const name of names) this.renderer.setAttribute(this.element.nativeElement, name, "");
  }
}

/** A native listener of each event a consumer passes, by the event's name (ADR-0118). */
type Listeners = { [K in keyof HTMLElementEventMap]?: (event: HTMLElementEventMap[K]) => void };

/**
 * Puts what a consumer passes the component, and the component does not declare, on the element
 * that takes it (ADR-0118): the attributes, the consumer's winning over the element's own, and
 * the native listeners, which run after the element's own.
 */
@Directive({ selector: "[ufFallthrough]" })
export class Fallthrough implements OnChanges, OnDestroy {
  readonly ufFallthrough = input.required<{
    attributes: Record<string, unknown> | undefined;
    listeners: Listeners | undefined;
  }>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);
  private readonly browser = isPlatformBrowser(inject(PLATFORM_ID));
  private readonly listening = new Map<string, { handler: unknown; stop: () => void }>();
  private written: Record<string, unknown> = {};

  ngOnChanges(): void {
    const element = this.element.nativeElement;
    const { attributes = {}, listeners = {} } = this.ufFallthrough();
    for (const name of Object.keys(this.written)) {
      if (!(name in attributes)) this.renderer.removeAttribute(element, name);
    }
    for (const [name, value] of Object.entries(attributes)) {
      if (value === null || value === undefined) this.renderer.removeAttribute(element, name);
      else this.renderer.setAttribute(element, name, String(value));
    }
    this.written = attributes;
    if (!this.browser) return;
    const handlers = new Map(Object.entries(listeners));
    for (const [event, { handler, stop }] of this.listening) {
      if (handlers.get(event) === handler) continue;
      stop();
      this.listening.delete(event);
    }
    for (const [event, handler] of handlers) {
      if (handler === undefined || this.listening.has(event)) continue;
      this.listening.set(event, { handler, stop: this.renderer.listen(element, event, handler) });
    }
  }

  ngOnDestroy(): void {
    for (const { stop } of this.listening.values()) stop();
  }
}
```

## Absent, undefined and null

A prop that is left out and a prop that is set to `undefined` are the same, on every target: the prop takes its default, or stays `undefined`. `null` is a value, and does not take the default.

`undefined` and `null` render nothing as text, and leave out an attribute they are bound to:

<!-- prettier-ignore -->
```tsx [ContactCard.uf.tsx]

}
```

## Names

A prop's name is ASCII letters and digits, starting with a letter: Angular's expression lexer reads no other letter. These names are reserved ([UF2003](/docs/reference/diagnostics#UF2003)):

- `key`, `ref`, `children`, `class`, `style`, `slot` and `is`, which the frameworks read themselves;
- `props`, `rawProps`, `constructor` and `Astro`, which the outputs declare beside the props, and `Fragment`, which Astro's output imports to render `<>`;
- JavaScript's reserved words, Angular's expression keywords (`as`, `let`, `typeof`, …) and the globals expressions may read (`Math`, `String`, …);
- event names such as `onClick`: a component declares its events with `defineEmits`, and the outputs name their event props after them ([Events](/docs/components/events#component-events)); names that start with `ng` and a capital letter, such as `ngIf`; and names that end in `$`, which Qwik reads as a lazy function.

A local type cannot take a name the outputs declare or import themselves, such as `CSSProperties`, `Component` or `Partial`. A type named `Props` is accepted when every component whose props reach it takes it as its props type: Astro's output declares a `Props` of its own for any other component.

## Not yet

- A conditional or mapped type, `keyof`, `typeof` or a template literal type in the props is [UF6002](/docs/reference/diagnostics#UF6002) under the default type oracle, which reads types as written ([What stays out](/docs/components/types-and-generics#what-stays-out)).
