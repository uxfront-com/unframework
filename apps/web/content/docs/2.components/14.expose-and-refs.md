title: Expose and component refs
description: defineExpose lists the functions a parent calls through a component ref. A ref on a component that exposes nothing holds its root element.
navigation:
  icon: i-lucide-plug
---

Sometimes a parent needs a child to act now, rather than when a prop changes: focus the search field, reset a counter, scroll a list to its end. A component lists what a parent may call with `defineExpose`, and the parent holds the component with a template ref, as it would hold an element ([Template refs](/docs/components/template-refs-and-ids#template-refs)), and calls what it exposes from client code.

## Exposing functions

`defineExpose` takes an object of the component's local functions, each in shorthand:

<!-- prettier-ignore -->
```tsx [SearchField.uf.tsx]
import { defineExpose, useTemplateRef } from "@uxfront/unframework";

export default function SearchField({ label }: { label: string }) {
  const input = useTemplateRef<HTMLInputElement>();
  function focus() {
    input.value?.focus();
  }
  defineExpose({ focus });
  return (
    <label class="search">
      {label}
      <input ref={input} type="search" />
    </label>
  );
}
```

<!-- prettier-ignore -->
```tsx [Header.uf.tsx]
import { useTemplateRef } from "@uxfront/unframework";

import SearchField from "./SearchField.uf.tsx";

export default function Header() {
  const search = useTemplateRef<{ focus(): void }>();
  return (
    <header class="header">
      <SearchField ref={search} label="Find" />
      <button type="button" onClick={() => search.value?.focus()}>
        Search
      </button>
    </header>
  );
}
```

The parent declares the ref with an object type of what it calls, `useTemplateRef<{ focus(): void }>()`, attaches it with `ref={search}`, and calls it in a handler, `search.value?.focus()`. The ref is `null` until the child is mounted, so the call reads it with `?.`:

::framework-switcher

import { type ComponentPropsWithoutRef, type Ref, useImperativeHandle, useRef } from "react";

export interface SearchFieldHandle {
  focus(): void;
}

export type SearchFieldAttributes = Omit<
  ComponentPropsWithoutRef<"label">,
  "label" | "children"
> & { ref?: Ref<SearchFieldHandle> };

export default function SearchField({
  label,
  className,
  style,
  ref,
  ...attributes
}: { label: string } & SearchFieldAttributes) {
  const input = useRef<HTMLInputElement>(null);

  function focus() {
    input.current?.focus();
  }

  useImperativeHandle(ref, () => ({ focus }));

  return (
    <label className={cx("search", className)} style={style} {...attributes}>
      {label}
      <input ref={input} type="search" />
    </label>
  );
}

/** Joins class names, and the keys of an object's truthy entries, into one `className`. */
function cx(...parts: unknown[]): string {
  const names: string[] = [];
  for (const part of parts) {
    if (typeof part === "string") {
      if (part) names.push(part);
    } else if (part && typeof part === "object") {
      for (const [key, on] of Object.entries(part)) {
        if (on) names.push(key);
      }
    }
  }
  return names.join(" ");
}

/**
 * Gives a root node of its component the scope attributes the component's styled parents put on
 * its host (ADR-0063), and takes them off the host, which keeps only `display: contents`.
 */
@Directive({ selector: "[ufScope]" })
export class ScopeAttributes implements OnInit {
  readonly ufScope = input_1.required<HTMLElement>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);

  ngOnInit(): void {
    const host = this.ufScope();

    if (!names) {
      names = host.getAttributeNames().filter((name) => name.startsWith("data-uf-"));
      for (const name of names) this.renderer.removeAttribute(host, name);
      scopes.set(host, names);

}

 * Puts what a consumer passes the component, and the component does not declare, on the element
 * that takes it (ADR-0118): the attributes, the consumer's winning over the element's own, and
 * the native listeners, which run after the element's own.
 */

  readonly ufFallthrough = input_1.required<{
    attributes: Record<string, unknown> | undefined;
    listeners: Listeners | undefined;
  }>();
  private readonly element = inject<ElementRef<Element>>(ElementRef);
  private readonly renderer = inject(Renderer2);
  private readonly browser = isPlatformBrowser(inject(PLATFORM_ID));
  private readonly listening = new Map<string, { handler: unknown; stop: () => void }>();
  private written: Record<string, unknown> = {};

  ngOnChanges(): void {
    const element = this.element.nativeElement;
    const { attributes = {}, listeners = {} } = this.ufFallthrough();
    for (const name of Object.keys(this.written)) {
      if (!(name in attributes)) this.renderer.removeAttribute(element, name);
    }
    for (const [name, value] of Object.entries(attributes)) {
      if (value === null || value === undefined) this.renderer.removeAttribute(element, name);
      else this.renderer.setAttribute(element, name, String(value));
    }
    this.written = attributes;
    if (!this.browser) return;
    const handlers = new Map(Object.entries(listeners));
    for (const [event, { handler, stop }] of this.listening) {
      if (handlers.get(event) === handler) continue;
      stop();
      this.listening.delete(event);
    }
    for (const [event, handler] of handlers) {
      if (handler === undefined || this.listening.has(event)) continue;
      this.listening.set(event, { handler, stop: this.renderer.listen(element, event, handler) });
    }
  }

  ngOnDestroy(): void {
    for (const { stop } of this.listening.values()) stop();
  }
}

}

  useVisibleTask$,

export default component$<
  { label: string } & Omit<PropsOf<"label">, "label" | "class" | "style" | "ref"> & {

      style?: CSSProperties;

>(({ label, class: className, style, ref, ...attributes }) => {

    input.value?.focus();

  useTask$(() => {
    exposeRef(ref, { focus });

 * Fills a consumer's component ref with what the component exposes, or empties it: Qwik has no
 * component instance for the ref to hold (ADR-0054).

function exposeRef(ref: Signal<object | undefined> | undefined, exposed: object | undefined): void {
  if (ref) ref.value = exposed;
}

::

- React passes the ref as a prop, `ref`, which the child fills with `useImperativeHandle`. The child exports the handle's type, `SearchFieldHandle`, and the parent reads `search.current`.
- Vue writes `defineExpose`, and the parent `useTemplateRef("search")` with `ref="search"`.
- Svelte exports each function from the component, `export function focus()`, and the parent binds a `let` with `bind:this`.
- Angular makes each exposed function a public method, and the rest protected where the template reads them, private otherwise. The parent writes a template reference, `#search`, and reads it with `viewChild`.
- Solid passes a `ref` callback, which the child calls with what it exposes, and the parent empties its `let` with `onCleanup`.
- Qwik has no component instance to hold, so the parent passes a signal as `ref`, and the child fills it with its `$` functions and empties it when it is removed, through an inline helper, `exposeRef` ([`expose`](/docs/reference/targets#capabilities), emulated).
- Astro renders on the server only, so nothing calls what a component exposes: the ref and its calls are dropped (`expose`, for information).

The argument is an object literal of local functions, by name: no state, no computed value and no function written in place ([UF2030](/docs/reference/diagnostics#UF2030)). Expose a function that reads or writes the state instead. A ref whose type names a function the component doesn't expose is [UF3046](/docs/reference/diagnostics#UF3046). A ref on a component that exposes nothing holds its root element ([below](#a-ref-on-a-component-that-exposes-nothing)).

## Several functions

A component may expose several functions, declared with `function` or as an arrow function:

<!-- prettier-ignore -->
```tsx [Counter.uf.tsx]
import { defineExpose, ref } from "@uxfront/unframework";

export default function Counter({ start }: { start: number }) {
  const count = ref(start);
  function increment() {
    count.value++;
  }
  const reset = () => {
    count.value = start;
  };
  defineExpose({ increment, reset });
  return <output class="count">{count.value}</output>;
}
```

The parent's ref type lists the ones it calls, `useTemplateRef<{ increment(): void; reset(): void }>()`, and each button calls one.

Call what a child exposes from client code only, as you'd read an element ref: a handler, a watcher's callback or a lifecycle hook ([Template refs](/docs/components/template-refs-and-ids#where-to-read-one)).

## A ref on a component that exposes nothing

A ref on a component that doesn't call `defineExpose` holds its root element, as Vue's `$el` does. It reaches through a chain of root components, and it holds the root whatever `inheritAttrs` says ([Fallthrough](/docs/components/fallthrough#refs)). Type it as that element's DOM interface, by its name:

<!-- prettier-ignore -->
```tsx [NameField.uf.tsx]
import { onMounted, ref, useTemplateRef } from "@uxfront/unframework";

// Exposes nothing, so a ref on it holds its root element. Its own template ref on that element
// still holds it once mounted, beside the parent's: `onMounted` reads it, and its focus listener
// fills the field only if it did.
export default function NameField({ label }: { label: string }) {
  const input = useTemplateRef<HTMLInputElement>();
  const mounted = ref(false);
  onMounted(() => {
    mounted.value = input.value !== null;
  });
  function fill() {
    if (input.value && !input.value.value && mounted.value) input.value.value = "Ada";
  }
  return <input ref={input} name="name" aria-label={label} onFocus={fill} />;
}
```

  useRef,
  useState,
} from "react";

export type NameFieldAttributes = Omit<ComponentPropsWithRef<"input">, "label" | "children">;

export default function NameField({
  label,
  className,
  style,
  onFocus,
  ref,
  ...attributes
}: { label: string } & NameFieldAttributes) {
  const input = useRef<HTMLInputElement>(null);
  const [mounted, setMounted] = useState(false);
  const mountedRef = useRef(mounted);

  const onMount = useEffectEvent(() => {
    mountedRef.current = input.current !== null;
    setMounted(mountedRef.current);
  });
  useEffect(() => {
    onMount();
  }, []);

  function fill() {
    if (input.current && !input.current.value && mountedRef.current) input.current.value = "Ada";
  }

  const rootRef = useMemo(() => mergeRefs(input, ref), [input, ref]);

  return (
    <input
      ref={rootRef}
      name="name"
      aria-label={label}
      onFocus={(event) => {
        fill();
        onFocus?.(event);
      }}
      className={className}
      style={style}
      {...attributes}
    />
  );
}

/** Joins an element's refs into one ref callback, whose cleanup clears each. */
function mergeRefs<E extends Element>(...refs: (Ref<E> | undefined)[]): RefCallback<E> {
  return (element) => {
    const cleanups = refs.map((ref) => {
      if (typeof ref === "function") {
        const cleanup = ref(element);
        return typeof cleanup === "function" ? cleanup : () => ref(null);
      }
      if (ref) ref.current = element;
      return () => {
        if (ref) ref.current = null;
      };
    });
    return () => {
      for (const cleanup of cleanups) cleanup();
    };
  };
}

::

- React passes the ref as React 19's `ref` prop, which reaches the root element. Where the root has a ref of its own, an inline helper, `mergeRefs`, joins the two into one ref callback, made once per pair with `useMemo`. The parent's ref is `useRef<HTMLInputElement>(null)`.
- Vue holds the child's instance, `useTemplateRef<{ $el: HTMLInputElement }>("nameComponent")`, and the parent's ref is a `computed` of its `$el`, the root element.
- Svelte gives the child a `$bindable` `ref` prop, `ref?: HTMLElementTagNameMap["input"] | null`, which its root binds beside its own ref through a function binding. The parent binds it to a `$state` ref, `bind:ref={name}`.
- Angular's host is no element a ref may hold, so the child declares `ufElement`, a `viewChild` of its root, `ElementRef<HTMLInputElement>`. The parent reads the child with `viewChild("name", { read: NameField })`, and its ref is a `computed` of that `ufElement` ([`expose`](/docs/reference/targets#capabilities), emulated).
- Solid passes a `ref` callback, which the child's spread hands the root element, beside the root's own `ref` callback.
- Qwik passes a signal as Qwik's own element ref, which the root fills beside its own ref, `if (ref) ref.value = element`.
- Astro renders on the server only, so the ref and its calls are dropped (`expose`, for information).

## Exposed functions or the element

A ref on a component that calls `defineExpose` holds only what it exposes, never the element too. One ref has one value of one type, and merging functions onto an element would collide with its members: an exposed `focus` would hide the element's own. A component that wants a parent to reach its element exposes a function that acts on it, as `SearchField`'s `focus` does above.

So a ref can't reach through a root component that exposes functions. On a component whose root is `<SearchField>` and that exposes nothing itself, a ref would hold `SearchField`'s `focus` on most targets, which the component doesn't expose, and its root element on Vue. So a ref on it is [UF3046](/docs/reference/diagnostics#UF3046). Expose a function from it too, or give it an element root.

The decisions behind this page are [ADR-0049](https://github.com/uxfront-com/unframework/blob/main/docs/adrs/0049-template-refs-and-ids.md), [ADR-0054](https://github.com/uxfront-com/unframework/blob/main/docs/adrs/0054-composition-on-every-target.md) and [ADR-0118](https://github.com/uxfront-com/unframework/blob/main/docs/adrs/0118-attributes-listeners-and-refs-fall-through.md).
